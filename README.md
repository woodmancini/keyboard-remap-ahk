### A relatively simple remap for Windows 11 that provides:
- a layer key on \ (left pinky) that activates navigation keys, mostly on the right hand
- a second layer key on Left Alt (left thumb) that activates numbers, shifted one row down from the usual position, and puts remaining punctuation keys under right fingers.
- remaps Left Alt to CapsLock (where it should be!)
- remaps Alt Gr (aka Right Alt) to Shift, to be used by the right thumb
